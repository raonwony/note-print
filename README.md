# 노트 인쇄

**열기: https://raonwony.github.io/note-print/** (iPad·폰은 Safari/Chrome에서 열고 “홈 화면에 추가”하면 앱처럼 쓸 수 있어요)

모눈(네모 칸·점·줄) 바탕 위에 글자·선·네모·칸 나누기를 올려 여러 쪽짜리 노트를 만들고,
**집에서 인쇄**하거나 **인쇄소에 보낼 PDF**로 내보내는 웹앱(PWA)입니다.

## 저장 (v1.2)
- 지금 만드는 노트는 고칠 때마다 이 브라우저에 **자동 저장**돼요(위쪽에 “✔ 자동 저장됨 시각” 표시). 창을 닫는 순간에도 마지막 수정까지 한 번 더 저장해요.
- 닫기 전에 “내 노트 저장”이나 “파일로 내보내기”를 하지 않은 변경이 있으면 브라우저가 한 번 확인해요. 귀찮으면 “내 노트” 창에서 끌 수 있어요.
- 자동 저장은 이 기기·이 브라우저 안에만 있어요. 다른 기기로 옮기거나 안전하게 보관하려면 “파일로 내보내기”를 쓰세요.

## 수정 반영 (v1.1)
- **안내선 표시**: 흰 쪽 = 재단 크기(가장자리가 곧 자르는 자리), 그 바깥 빗금 띠 = 도련(종이 밖, 잘려 나가는 부분, 빨간 점선까지 배경 채움), 안전선=파란 점선. 작업 화면 위에 범례가 있어요.
- **표**: 칸을 한 번 누르면 칸이 골라지고 같은 칸을 한 번 더 누르면 글자를 써요(“이 칸에 글자 쓰기” 단추·Enter도 가능). 행·열 수를 숫자로 바꿀 수 있어요.
- **도형**: 둥근 네모는 모서리 둥글기를 mm로 조절하고(완전 둥글게 단추), 가로세로 비율 고정 단추가 생겼어요(숫자 입력·끌기 모두 적용).
- **바탕 모눈**: 모눈이 그려지는 범위(노트 가장자리에서 안쪽 여백), 시작 위치(가운데 맞춤 / 범위의 왼쪽 위부터), 가로·세로 이동을 정할 수 있어요(화면·집 인쇄·PDF 모두).
- **가이드선**: 위아래·좌우 2~24등분 자동 만들기(노트 전체/안전선 안쪽 기준), 색 바꾸기, 잠금, 여러 개 함께 고르기(Shift), 가이드선 묶음 저장·불러오기(더하기/바꾸기).

## 5단계 (v1.0): 집에서 인쇄(양면·자르는 점선) · 바탕 굵기 · 인쇄소 점검
- **집에서 인쇄 → 양면 인쇄**: 켜면(바인더 노트는 기본) 1쪽=앞면·2쪽=뒷면이 같은 종이 뒤에 겹치도록, 뒷면 배치를 좌우(긴 변 기준) 또는 위아래(짧은 변 기준)로 거울처럼 뒤집어 앞면·뒷면을 번갈아 만들어요. 쪽수가 홀수면 마지막 뒷면은 모눈만 있는 빈 쪽이에요. 프린터 인쇄 창에서는 "양면 인쇄 — 긴 변(또는 짧은 변) 기준 넘기기"를 고르세요.
- **자르는 선**: "점선(재단기용)" = 노트 가장자리를 따라 용지의 인쇄 가능한 가장자리(약 3mm)에서 반대쪽까지 이어지는 점선. "모서리 표시"·"없음"도 고를 수 있어요. 노트 사이를 4mm쯤 띄우면 선이 빈 틈에 놓여요. 인쇄소용 PDF에는 들어가지 않아요.
- **바탕**: 모눈·줄은 "선 굵기", 점은 "도트 크기"를 mm로 고를 수 있어요(화면·집 인쇄·PDF 모두).
- **PDF 점검 표**: 만든 뒤 레드프린팅 규칙(도련 5mm, 재단선 표시 없음, 낱장·1쪽 오른쪽부터, 쪽수 규칙, CMYK·글꼴 포함)을 ✔/⚠로 보여줘요.

## 4단계 (v0.9): 새 파일 만들기 · 쪽 번호 · 링 구멍 · 4의 배수
- **새 파일**(위쪽 "새 파일"): 바인더용 속지 / 노출제본 속지 → 크기(바이블 6공, A5, A6 6공, M5 5공 / A6, A6 슬림, B6, B6 슬림, A5, A7, B7 / 사용자 지정) → 쪽 수 → 쪽 번호 → 바탕. 처음 열 때 한 번 자동으로 떠요.
- **노출제본**: 쪽 추가는 4쪽씩. 지워서 4의 배수가 깨지면 작업 화면 위에 경고와 "빈 쪽 N개 추가" 단추가 계속 떠 있고, PDF는 4의 배수가 아니면 "빈 쪽 N개 추가하고 PDF 만들기"로만 만들 수 있어요.
- **바인더**: 쪽은 1쪽씩 추가. PDF 쪽수가 홀수면 양면 인쇄용으로 끝에 빈 쪽 1개를 붙여서 내보내요(노트 파일에는 안 더해져요).
- **링 구멍 가이드**(바인더): 크기별 기본 간격(바이블 19/19/51/19/19, A5 19/19/70/19/19, A6 19/19/38/19/19, M5 19×4)을 자동 입력. 종이 세로 가운데 기준 위아래 대칭, 홀수 쪽은 왼쪽·짝수 쪽은 오른쪽. 지름 3~6mm, 가장자리 거리·간격 수정 가능. 가장자리 거리·지름은 확정 자료가 없는 **추정값**이라 실물을 재서 고쳐 주세요. 인쇄·PDF에는 들어가지 않는 안내선이에요.
- **쪽 번호**: 새 파일에서 가로(바깥 가장자리/가운데)·세로(아래/위)·시작 번호를 고르고, 만든 뒤에도 "문서·쪽" 탭에서 바꿀 수 있어요. 어떤 쪽만 끄거나 위치를 따로 정할 수도 있어요. 화면·집 인쇄·PDF 모두에 들어가요.

## 3단계 (v0.8): 오른쪽 작업창 · 펼침면 쪽 목록
- 오른쪽 작업창이 탭으로 바뀌었어요: **문서·쪽**(쪽 목록, 용지·도련, 바탕) / **개체**(고른 것의 자세한 설정, 개체 목록) / **색**. 개체를 고르면 자동으로 "개체" 탭이 열리고, 빈 곳을 누르면 "문서·쪽"으로 돌아와요.
- "넣기" 도구(글자·선·도형·표·이미지)는 작업 화면 위 띠로 옮겼어요.
- 쪽 목록은 펼침면 모양: 1쪽은 첫 줄 오른쪽에 혼자, 아래 줄부터 2·3쪽이 왼쪽·오른쪽 한 쌍.
- 쪽 하나 누르면 열기, Shift=범위 선택, Cmd/Ctrl=하나씩 더하기·빼기. 고른 쪽들을 끌면 한꺼번에 순서가 바뀌어요(분홍 막대가 놓일 자리, 터치는 ⠿ 손잡이로). 복제·삭제·◀▶(한 칸씩 이동)도 여러 쪽에 한꺼번에 돼요.
- 투명한 PNG는 투명 그대로 들어가요(화면·PDF).

## 3차 추가 (v0.7): 색 · 이미지
- 기본 색 세트: 검정·회색 4가지 + iLang 브랜드 색 8가지(Ink Black, Charcoal, Stone Gray, Warm Gray, Soft Ivory, Paper White, iLang Orange, Ripple Blue — 브랜드 색상표 PDF 7쪽의 CMYK 값 그대로) + 어울리는 녹색 1가지(Leaf Green, 임의로 추가한 색: C22 M0 Y32 K30). 브랜드 색의 이름·값은 고칠 수 있어요.
- 내 색: 최대 12개까지 추가·삭제·이름 바꾸기. 색 동그라미를 눌러 화면에서 고르면 CMYK로 자동 변환되고, 숫자를 직접 적어도 돼요. 쓰던 색을 지우면 검정으로 바뀌어요.
- 이미지(JPG·PNG): "＋ 이미지"나 끌어다 놓기. 모서리 손잡이=비율 유지 크기 조절, 가장자리 손잡이=자르기. 회전·흑백(검정 한 가지)·원래 비율·사진 바꾸기. 사진은 브라우저 안(IndexedDB)에 저장되고, "파일로 내보내기"에는 사진도 함께 들어가요.
- 인쇄소용 PDF: 사진은 인쇄용 CMYK로 바꿔 넣고(크기에 맞춰 최대 300dpi), 해상도가 300dpi보다 낮으면 알려줘요. 투명한 PNG의 투명한 곳은 흰색으로 들어가요. 컬러 사진은 변환 때 색이 달라질 수 있으니 인쇄소에서 시안 확인을 권해요.

## 2단계에서 추가된 것 (v0.6)
- 도형: 네모, 둥근 네모, 타원/원, 삼각형, 별(꼭짓점 수 조절), 자유곡선(끌어서 그리기, 처음과 끝을 가까이 하면 닫힌 모양)
- 선: 끝·시작에 화살표 넣기
- 닫힌 도형: 색 채우기(농도 %), 안쪽 무늬 채우기(도트·격자·줄 — 색·굵기(도트 크기)·간격 선택)
- 표: 행·열 추가/삭제, 칸 합치기/풀기, 칸마다 글꼴·크기·정렬·세로 위치·색·채우기, 칸 사이 선을 끌어 너비·높이 조절. (예전 "칸 나누기"는 표로 바뀌어요)
- 잠금: 잠그면 끌기·방향키·숫자 입력·정렬·크기 조절 모두 막힘
- 인쇄소용 PDF에 위 도형·표·화살표가 모두 벡터로 들어감 (이미지 넣기는 아직 없음)

## 1단계에서 추가된 편집 기능 (v0.5)
- 눈금자(mm)에서 끌어내 가이드선 만들기(이 쪽만 / 모든 쪽), 옮기기·숫자 입력·끌어서 밖으로 놓으면 삭제
- 스마트 가이드: 옮기거나 크기를 바꿀 때 가이드선·쪽 가장자리/중앙·다른 개체에 자석처럼 붙고 보조선 표시 (Alt를 누르면 잠시 끔)
- 여러 개 선택(영역 드래그·Shift/Cmd 클릭·Cmd+A), 8방향 크기 핸들, 회전 핸들(Shift=15도씩), 선은 양쪽 끝점 핸들
- 위치·크기·회전각 숫자 입력, 정렬·같은 간격 배열, 순서(앞/뒤), 묶기(Cmd+G), 잠금·숨기기, 복사·붙여넣기(쪽 사이도), 서식 복사
- Ctrl+휠·두 손가락 벌리기로 확대, 스페이스+끌기로 화면 이동
- 도련·안전선 기본 5mm, 인쇄소용 PDF는 재단선 표시 없이(기본) 도련 포함 크기로 내보냄

## 쓰는 법 (이전 설명)
1. **① 용지 크기·도련**: A4~B7, M5(바인더 미니5) 중에서 고르거나 mm로 직접 적습니다. 자주 쓰는 크기(예: 슬림)는 "이 크기 저장"으로 목록에 남깁니다.
   - 도련 = 자르다 어긋나도 흰 틈이 안 생기게 배경을 재단 크기 바깥으로 사방 더 그려 두는 여분(기본 5mm). 화면의 흰 쪽 = 재단 크기(쪽 가장자리가 곧 자르는 자리), 빗금 띠 = 도련, 파란 점선 = 안전선(중요한 글자는 안쪽에).
2. **② 바탕**: 모든 쪽에 한꺼번에 깔리는 밑그림. "바탕 꾸미기"로 들어가 모눈(모양·간격·진하기·색)과, 모든 쪽에 반복할 선·칸 나누기·쪽 번호를 넣습니다. 바탕은 여러 개 만들 수 있고 쪽마다 고를 수 있습니다.
3. **③ 넣기**: 글자 · 선 · 네모 · 칸 나누기. 끌어서 옮기고, 둥근 점으로 크기를 바꿉니다(모눈 칸에 맞춰 붙음). 글 속에 `{쪽}`, `{전체}`를 쓰면 쪽 번호·전체 쪽 수로 바뀝니다.
4. **쪽 관리**(아래쪽 줄): 쪽 추가·복제·삭제·순서 바꾸기, 쪽 목록(썸네일).
5. **⑤ 색**: 검정·회색 3단계(먹 K만 사용) + 포인트 색 2개(CMYK %로 직접 지정).
6. **집에서 인쇄**: 노트 크기 그대로 한 쪽씩, 또는 A4 등 큰 용지에 모아 찍기(자르는 선 가능). 인쇄 창에서 배율 100%·여백 없음.
7. **인쇄소용 PDF**: 쪽마다 한 장씩, 재단 크기+도련(+재단선) 크기로 내보냅니다.
8. **내 노트**: 이름 붙여 저장·불러오기, 파일(.json)로 백업.

## 인쇄소용 PDF가 하는 일
- 쪽마다 용지 = 재단 크기 + 도련 (재단선 옵션을 켜면 사방 8mm 더, 모서리 자르는 표시와 쪽 번호 포함). TrimBox/BleedBox가 파일에 기록됩니다.
- 모눈·선·글자 전부 벡터(해상도 걱정 없음). 이미지는 아직 넣을 수 없습니다.
- 색은 CMYK. 검정은 K 100% 한 가지(4색이 섞이지 않아 가는 글씨가 번지지 않음).
- 글꼴은 통째로 파일에 포함(인쇄소에 글꼴이 없어도 같게 나옴). 그래서 파일이 1~7MB 정도 됩니다.
- 내보낼 때 점검: 글꼴에 없는 글자, 안전선 밖으로 나온 글자를 알려줍니다.

### 한계 (솔직히)
- 인디자인이 만드는 정식 인쇄 규격(PDF/X) 인증 파일은 아닙니다. 인쇄소 검사 프로그램이 경고를 낼 수 있어요. 인쇄소의 "입고 가이드"를 확인하세요.
- 별색(팬톤) 1도·2도 인쇄, 표지·책등(스파인) 계산, 제본용 쪽 배열(중철 등)은 아직 없습니다. 바인더 속지·낱장·무선/노출제본 내지는 "쪽 순서 그대로"가 기본이라 대부분 그대로 맡길 수 있습니다.
- 화면 색은 CMYK를 단순 환산한 것이라 실제 인쇄색과 조금 다릅니다. 컬러는 인쇄소 색상 견본/시안으로 확인하세요.

## v1.3 글자·정렬·뒤집기
- **글자 일부만 크기·색 바꾸기**: 글자 상자를 “글자 고쳐 쓰기”로 열고, 바꿀 글자를 끌어서 고른 뒤 오른쪽 “개체” 탭의 “선택한 글자만 바꾸기”에서 크기·색을 바꿔요. 상자 전체 크기·색을 바꾸면 일부 글자 서식은 걷어내고 통으로 바뀌어요. (글꼴·굵게는 상자 전체만)
- **정렬 5가지**: 왼쪽 · 가운데 · 오른쪽 · 양쪽(여러 줄의 양 끝을 상자에 맞춤, 문단 마지막 줄 제외) · 균등(짧은 한 줄도 글자 사이를 벌려 상자 폭에 꽉 채움). 화면과 PDF가 같은 규칙으로 줄을 나눠요.
- **좌우 뒤집기 / 좌우 뒤집어 붙여넣기**: 고른 것들을 쪽 가운데 기준으로 좌우 뒤집어요(홀수 쪽 ↔ 짝수 쪽 배치).
- 가이드선 묶음(묶기·같이 끌기·숫자로 옮기기·좌우 뒤집기), 쪽 아래 줄에서 Shift/Ctrl로 여러 쪽 고르기(파란 테두리 표시).
